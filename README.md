# Mentorship Platform

A full-stack mentorship matching platform that connects mentees with suitable mentors on 1-on-1 interactive sessions.

---

## Deployed URL: https://mentorship-platform-nine.vercel.app/index.html

---

## Technologies Used

| Part | Tech |
|------|------|
| **Frontend** | HTML, CSS, JavaScript |
| **Backend** | Node.js, Express.js |
| **Database** | MySQL |

---

## Features

- User authentication (Sign up / Login / Logout)
- User profile creation and management
- Mentor/Mentee discovery and filtering
- Mentorship request system (Send / Accept / Decline)
- Fully responsive design (Mobile friendly)

---

##  Setup Instructions

### 1 Clone repository


- git clone https://github.com/TranKhoaa/mentorship-platform/tree/main
- cd mentorship-platform
### 2 Clone repository
- Navigate to the backend folder 
- Install backend dependencies: 
    + npm init -y
    + npm install express mysql2 dotenv bcrypt jsonwebtoken cors
- Navigate to the frontend folder
- Open index.html directly in your browser to run locally or visit the deployed site here:https://mentorship-platform-nine.vercel.app/index.html
